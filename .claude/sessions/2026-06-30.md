- Root cause: `ProvenanceGraph` mutations happen outside Angular zone (WebGL event listeners), so default CD never ran and `_isEmpty` getter never re-evaluated.

## Decisions Made

- **Service-based tree registration over window globals**: Components write `provenance.tree = this` in `ngOnInit` rather than `window.tree = this`. Avoids timing issues (window global set before component is mounted) and removes implicit global coupling.
- **`detectChanges()` not `markForCheck()`**: Component uses default CD strategy (CheckAlways), so `markForCheck()` is a no-op — `detectChanges()` is needed to force immediate re-evaluation.
- **`rewire()` method**: Graph reset creates new `ProvenanceGraph` + `traverser` — the viz component needs to free the old D3 tree and create a new one. Separate `rewire()` method makes this explicit rather than re-creating the Angular component.
- **No modular refactor**: Described full SharedModule / ViewerFacadeService architecture but did not implement — it's a high-churn refactor with no functional benefit for a single-dev project at this stage.
